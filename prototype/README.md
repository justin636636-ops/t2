# 怪物打靶夜 · 3D 可玩原型

更新于 2026-10-02。以设计文档 v0.4 的 A～C 阶段为范围，验证一关的「准备 → 收割 → 培养 → 下一组兑现」。Godot 4 原生 3D 项目，已接入原创模型、材质、灯光、界面，以及主要角色动作和特效。本机验证版本为 Godot 4.7.2，采用 Forward+ / Metal 渲染；运行不依赖 Blender 或外部插件。

## 试玩

双击上一级目录的 **试玩怪物打靶夜.command**，点击「开场营业」。也可在 Godot 中导入本目录的 `project.godot`，按 F5 运行主场景。

命令行运行：

```sh
/Applications/Godot.app/Contents/MacOS/Godot --path /Users/gaoping/Documents/t2/prototype
```

| 操作 | 行为 |
| --- | --- |
| 鼠标移动 / 左键 | 瞄准 / 射击；只在射击舞台点击才消耗弹位 |
| 按住右键 | 轻微收窄视野聚焦 |
| 长按 R 0.35 秒 | 提前报分；释放取消；至少开过一枪才能提交 |
| Tab / Esc | 暂停并查看桌面；每组第一枪前可调整配置 |
| Space / Enter | 报分或最后一枪退场期间，立即进入下一组或查看关卡结果 |
| 声音按钮 | 开关合成射击、命中、弹簧和报分音效 |
| 声音与动态 | 音量与减少动态；键盘 Tab 切换焦点，Esc 返回 |

建议第一轮这样玩：

1. 默认第一发弹簧，打前排任一气球怪，观察它真实上抛。
2. 用第二发普通弹射击它的刻口靶心，完成精准、空中特技与准备接力。也可以等落地，观察地毯再弹一次后收割。
3. 长按 R，交出剩下三发；发条鸭得到 3 储能，升级到一级。
4. 进入下一组，射中右侧黄色铃铛。海盗翻盖，鸭子牵住其中一个 0.8 秒；用后续普通弹打它。
5. 试试打满五发和提前培养的收益差异。Tab 中可切换全普通弹、首发弹簧、第三发弹簧，也可卸下地毯作对照。

## 已实现

- 真实 3D 摊位、双层轨道、海盗船和夜海绘景、夜园灯串、错缝石板地面；原创怪物、海盗、盾牌、玩具左轮与发条鸭模型。
- 固定站位，鼠标指向瞄准；四组五发、60 秒、累计达到 1,800 分过关。
- 普通与弹簧两种芯；五枚装填组件独立编号，组间保留，同一弹簧芯换位后编号不变。
- 身体破坏、弱点破坏、破盾、准备、空枪和未射分开记录；非致命弹簧基础分为零。
- 弹射和地毯改变目标真实位置，射线读取移动后的碰撞；地毯每靶每组只再弹一次。
- 可射铃铛翻盖，关联真实海盗；后续击破关联目标才能完成准备接力。
- 连中、精准、空中特技、准备接力。规则结算器还支持一枪多响，当前单发左轮不产生该表演。
- 靶纸卷、节拍器、笑脸弹簧按固定顺序报分；五气球算例 3375，与换序算例 2875 均有测试。
- 发条鸭按主动交出的真实余弹成长；空报、只有空枪、打满五发和时间强制结束不奖励。下组生效，每组首次有效机关触发一次帮助。
- 暂停、配置锁定、重开、过关/失败、报分明细、分数预览、音效开关，以及失去应用焦点时自动暂停。

## 与完整版的范围差异

首轮预置五件测试奖品和一枚弹簧芯，不模拟购买。仅有一关，商店、Boss、其他武器与六类特殊弹芯、喂龙、采收、存档和完整章节尚未实现。当前弹芯配置采用三个预设，不含任意拖拽库存或奖品排序。

为方便检查公式与培养，报分默认手动继续。当前武器为即时射线，没有待决伤害投射物；可见弹道仅为视觉反馈，不需要额外等待 1.2 秒。靶运动使用轨道加受限抛物线，不是全场自由刚体。固定摄像机暂不支持转头。「旧玩具夜园」已加入眨眼、视线、扬眉、差异手势、弹起形变、退场复位、翻盖破盾、握枪与后坐、鸭子动作、分材质特效和界面演出。幕布与船帆形变、真实回弹软垫、实体弹簧、两种弹道和简短开场/胜负演出已实现。真实枪口收敛、五发弹仓、扳机、独立嘴部/耳朵/天线、差异击破和木牌底部铰点已实现；第五枪先退场再淡入报分卡，键盘可随时继续。五种身体轮廓、脸部比例与配饰各有差异，带有间歇性的个性动作。舞台加入开场/机关/胜负灯串节奏、实体奖品升降与左侧结算卡，隐藏结束时的无效 HUD，并可从结算直接进入声音与动态设置。已深化弧形夜海绘景、分层波浪、铺装地面、漆面/布面/木材区别与主补光。已加入七种真实结果标记、分强度细火花、精准击破两音瓷铃与底部接力铭牌；反馈和弹票动画同步暂停，成功命中清除旧阻挡提示，重开清理旧反馈。上一轮将招牌改为彩绘异形牌与真正的立体字，加入怪物刻饰、港湾剪影、边缘灯笼、月面颜料细节，以及锚/帆船前裙板嵌饰。新增装饰合为八个不透明材质批次，不新增物理、灯光或每帧更新。上一轮加入最多两名附近角色对真实命中的短暂注意力反应、一次换组灯光和差异胜负收势，暂停/重开/减少动态同步。上一轮重塑圆润搪瓷船体、弧形木护舷与铆接细节，船帆加入裁片、修补、缝线、包边和系扣；独立低对比布料着色保留暂停/减少动态。上一轮报分改为纸质靶票，按真实规则顺序落印，最终分数即时可读；继续操作保持即时，减少动态显示静态完整结果。发条鸭已加入双色搪瓷外壳、机械细件与作者升级装配，眼/下喙跟随颈部，帮助回望实际海盗、成长与胜负短表情；暂停/复位同步，减少动态取消持续钥匙/身体动作，成长/领奖按真实脚底补偿位置。更完整的关卡演出、实际游戏尺度下的角色识别与数值平衡仍需继续制作和试玩。
