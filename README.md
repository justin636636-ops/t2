# 怪物打靶夜

Godot 4 原生 3D 可玩原型及其最终 v0.4 设计文档。

- 原型入口与操作说明：[prototype/README.md](prototype/README.md)
- 最终设计文档：[Markdown](怪诞射击摊位游戏设计文档_v0.4.md) · [Word](怪诞射击摊位游戏设计文档_v0.4.docx)
- 最终界面示意图：[怪物打靶夜设计素材_v0.4](怪物打靶夜设计素材_v0.4/)

使用 Godot 4 打开 `prototype/project.godot` 开始试玩。macOS 上也可运行 `./试玩怪物打靶夜.command`。

仓库保留可运行源码、测试、游戏资源和最终设计交付物。生成的美术工作区、历史备份、过程记录、渲染证据和 Godot 缓存不纳入版本控制。
